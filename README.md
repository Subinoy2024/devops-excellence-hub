# DCCloud - DevOps Excellence Hub

## About

AI-powered DevOps Engineer Portfolio by Subinoy Debnath — showcasing Cloud & DevOps expertise across Azure, AWS, Terraform, Kubernetes, and CI/CD automation.

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Development

```sh
# Clone the repository
git clone https://github.com/Subinoy2024/devops-excellence-hub.git

# Navigate to the project directory
cd devops-excellence-hub

# Install dependencies
npm i

# Start the development server
npm run dev
```

## Deployment

This project is deployed via GitHub Pages using GitHub Actions. Push to the `main` branch to trigger automatic deployment.
